공장 라벨 검수·자동 전환 시스템

카메라로 제품을 세고 라벨을 대조해 태블릿에 보여주고, 라벨 바꿀 때를 스스로 알려주는 시스템 — 가능성·방향 검토 (기계 사진 확인함 · 확정 견적은 현장 실사 후)

한 줄 결론

확실히 됨  앞·뒤 카메라로 세고 대조해 태블릿에 실시간 표시
됨  라벨을 바꿀 때를 스스로 감지해 알림 (개수 미리 입력 안 함)
기계 확인됨  라벨 = 용기에 붙이는 인쇄된 덮개 필름(롤) → 롤 자동 교체는 배보다 배꼽이라 “바꾸세요” 알림 + 바꾼 뒤 카메라 재확인이 정답

기계 확인 결과 · 사진 받음 (2026-09-14)

보내주신 기계는 자동식 용기포장기 (TPS-TS4E · MAP포장) — 용기 위에 인쇄된 덮개 필름을 열로 붙여 밀봉하는 실링기입니다. 조작판엔 온도 조절기(접착온도·날인온도)만 있습니다.

그래서 “라벨을 바꾼다” = 필름 롤을 손으로 갈아 끼우는 일입니다. 기계에 신호를 보내거나 버튼을 눌러 바뀌는 게 아니라, 물리적으로 롤을 교체합니다.
  • 롤을 자동으로 갈아 끼우는 장치는 비전 시스템 전체보다 비싸고, 밀봉 품질까지 건드려 위험 → 권장하지 않습니다.
  • 대신 “이제 단호박 롤로 바꾸세요” 알림 + 바꾼 뒤 카메라가 새 필름이 맞는지 재확인 → 엉뚱한 롤을 끼우면 즉시 잡아냅니다. 사장님이 걱정하신 오라벨은 여기서 막힙니다.
  • 세고 대조하는 카메라(요청 1·2)는 이 기계 그대로 전부 됩니다 — 기계는 손 안 댑니다.

보너스: 온도 조절기가 통신형(RS-485)이면 접착·날인 온도를 태블릿에서 같이 모니터링해 밀봉 불량도 예방 가능 (현장 모델 확인 시).

요청 3가지, 각각 되는지

1앞·뒤 카메라로 세서 대조 → 태블릿 표시 확실히 됨

  • 1~2초마다 두 카메라가 촬영 → 제품 종류와 개수를 자동 인식
  • 라벨 전(실물 수)과 라벨 후(라벨 수)를 대조, 안 맞으면 즉시 경보
  • 라벨의 글자·바코드까지 확인 → 엉뚱한 라벨(한우오색 자리에 단호박)도 잡아냄
  • 태블릿엔 품목별 실시간 집계 표 (실물 / 라벨 / 차이)
예: 실물 12개 · 라벨 14개 → “라벨 2개 초과” 빨간 경보로 바로 표시
팁 — 라벨에 바코드가 있으면 뒤 카메라를 바코드 리더로 두는 방법이 있습니다. 그러면 검수 정확도가 거의 100%, 비용도 더 쌉니다.

2라벨 바꿀 때를 스스로 감지 → 알림 됨

  • 레일 위 제품 종류를 계속 인식 → 한우오색이 끝나고 단호박이 시작되는 순간을 자동 감지
  • “이제 단호박으로 바꾸세요” 알림 (태블릿·소리)
  • 요청하신 대로 개수를 미리 입력하지 않습니다 — 그냥 보고 판단
  • 쟁반을 올리기 전 한 장 찍어두면 다음에 뭐가 올지 미리 알 수도 있음 (선택)

3제어 기능 없는 기계에 보조장치로 제어 추가 알림형 권장

지금 바로 되는 것 — “바꿀 때”를 감지해 사람에게 알림. 기계 손 안 대고, 위험 0. 가치의 대부분이 여기서 나옵니다.
기계를 자동으로 바꾸는 것은 기계에 달렸습니다:
  • 랜·시리얼 포트가 있고 디지털로 라벨을 바꾸는 기계 → 명령을 보내 자동 전환 (가장 깔끔)
  • 버튼만 있는 기계 → 버튼 위에 누르는 장치(작은 액추에이터·릴레이)를 얹어 자동화
  • ← 이번 기계가 여기 해당. 라벨 롤을 손으로 갈아 끼우는 방식 → 자동화는 로봇팔급이라 배보다 배꼽 → 알림만 권장

→ 사진으로 확인한 결과 이번 기계는 세 번째(손으로 롤 교체)입니다. 그래서 알림형으로 갑니다.

2
선택 (자동 제어)기계가 허용하면 라벨 전환까지 자동으로. 기계 실사 후 결정.

이제 필요한 것 · 기계 확인됨, 남은 건 아래

  • 기계 모델 → 확인됨 (TPS-TS4E 용기포장기 · 필름 실링)
  • 제품 종류 목록 + 품목별 샘플 사진 몇 장 (한우오색·단호박 등 — 인식 학습용)
  • 지금 필름 롤 바꾸는 장면 영상 짧게 — 몇 초 걸리는지, 얼마나 자주 바꾸는지
  • 레일 속도와 그 자리 조명 상태, 필름·용기에 바코드 있는지
  • 카메라 달 레일 앞·뒤 공간 사진 (설치 위치 잡기용)

안전

  • 카메라 시스템은 지켜보기만 — 기존 생산 라인을 멈추거나 기계를 바꾸지 않습니다.
  • 기계 개조(2단계)는 현장 실사·안전 확인 후에만 진행합니다.

정확한 비용·일정은 기계 실사 후 확정됩니다.
