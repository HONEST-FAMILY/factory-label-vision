공장 라벨 검수·자동 전환 시스템

카메라로 제품을 세고 라벨을 대조해 태블릿에 보여주고, 라벨(찍는 제품)을 자동으로 바꿔주는 시스템 — 가능성·방향 검토 (기계 사진 3장 확인함 · 확정 견적은 현장 실사 후)

한 줄 결론

확실히 됨  앞·뒤 카메라로 세고 대조해 태블릿에 실시간 표시
됨  라벨을 바꿀 때를 스스로 감지 (개수 미리 입력 안 함)
됨  라벨기가 디지털 코더(Domino)라, 카메라가 제품을 알아보면 찍을 제품을 자동으로 바꿔줄 수 있음 — 로봇팔·롤 교체 필요 없음

기계 확인 결과 · 사진 3장 확인 (2026-09-14)

보내주신 기계는 자동식 용기포장기(TPS-TS4E)에 Domino 디지털 코더(열전사 프린터 · V시리즈)가 붙어 있는 구조입니다. 이 코더가 포장 필름 위에 제품명·원재료·제조일자·소비기한까지 글자를 직접 인쇄합니다.

핵심 — 코더 화면에 “현재 메시지: C069 고구마스프”라고 떠 있습니다. 즉 제품 하나하나가 코더 안에 ‘메시지(양식)’로 저장돼 있고, 제품을 바꾼다 = 저장된 메시지를 골라 바꾸는 일입니다. 롤을 손으로 갈아 끼우는 게 아닙니다.
정정 — 앞선 검토에서 라벨을 ‘인쇄된 필름 롤 수동 교체’로 봤던 것은 오판이었습니다. 사진 3장(조작판·Domino 몸체·Domino 터치스크린)을 다시 확인해 디지털 코더로 바로잡았습니다.
  • 이 코더(Domino V시리즈)는 바깥에서 메시지를 골라 바꾸는 기능을 정식 지원합니다(랜선·시리얼·자동화 게이트웨이). 사람이 손으로 ‘메시지들’에서 고르는 그 동작을, 우리 시스템이 명령으로 대신합니다.
  • 그래서 요청 3(자동 전환)은 로봇팔 같은 게 필요 없습니다. 카메라가 “이번엔 단호박” 하고 알아보면, 코더에 ‘단호박 메시지 찍어’ 신호만 보내면 됩니다.
  • 코더는 이미 제조일자·소비기한을 자동으로 올려 찍고 있어서, 우리는 “어느 제품이냐”만 자동으로 골라주면 됩니다.

집계·경보

카메라는 라인을 지켜보기만 하고, 코더에는 사람이 손으로 하던 ‘메시지 고르기’와 똑같은 신호만 보냅니다 — 라인을 멈추거나 기계를 개조하지 않습니다.

요청 3가지, 각각 되는지

1앞·뒤 카메라로 세서 대조 → 태블릿 표시 확실히 됨

  • 1~2초마다 두 카메라가 촬영 → 제품 종류와 개수를 자동 인식
  • 라벨 전(실물 수)과 라벨 후(라벨 수)를 대조, 안 맞으면 즉시 경보
  • 코더가 찍은 글자·바코드까지 확인 → 엉뚱한 제품(고구마스프 자리에 단호박)도 잡아냄
  • 태블릿엔 품목별 실시간 집계 표 (실물 / 라벨 / 차이)
예: 실물 12개 · 라벨 14개 → “라벨 2개 초과” 빨간 경보로 바로 표시
팁 — 라벨에 바코드가 있으면 뒤 카메라를 바코드 리더로 두는 방법이 있습니다. 그러면 검수 정확도가 거의 100%, 비용도 더 쌉니다.

2라벨 바꿀 때를 스스로 감지 됨

  • 레일 위 제품 종류를 계속 인식 → 고구마스프가 끝나고 단호박이 시작되는 순간을 자동 감지
  • 요청하신 대로 개수를 미리 입력하지 않습니다 — 그냥 보고 판단
  • 쟁반을 올리기 전 한 장 찍어두면 다음에 뭐가 올지 미리 알 수도 있음 (선택)

3기계를 조작해 찍을 제품을 자동으로 바꾸기 됨

됩니다. 이 기계는 ‘제어 기능이 없는’ 기계가 아니라, 이미 디지털로 제어되는 Domino 코더입니다. 사람이 터치스크린에서 메시지를 고르던 걸, 바깥에서 명령으로 고르게 하면 됩니다.
  • 자동 전환 — 코더 랜선·시리얼로 메시지 자동 선택. 카메라가 제품을 알아보는 순간 코더가 그 제품 라벨로 바뀝니다.
  • 닫힌 검증 — 바꾼 뒤 카메라 B가 실제로 찍힌 글자·바코드를 읽어 맞게 바뀌었는지 재확인 → 엉뚱한 라벨을 원천 차단. 사장님이 걱정하신 오라벨이 여기서 막힙니다.
  • 확정 전 확인 한 가지 — 이 코더의 정확한 세부 모델과 열려 있는 포트(랜/시리얼)만 확인하면 배선·비용이 바로 나옵니다. (기계에 붙은 Domino AS 콜센터 또는 프린터 몸체 라벨로 확인) 되는지 여부는 확정 — 됨.

이제 필요한 것 · 기계 확인됨, 남은 건 아래

  • 기계 종류 → 확인됨 (Domino 디지털 코더 · V시리즈 · 터치스크린)
  • 코더의 정확한 세부 모델 + 열린 포트(랜/시리얼) — Domino AS(기계에 붙은 콜센터) 또는 프린터 몸체 라벨로 확인. 자동 전환 배선·비용 확정용
  • 코더에 저장된 제품(메시지) 목록 (한우오색·단호박·고구마스프 등 — 카메라 인식과 자동 선택 매칭용)
  • 품목별 샘플 사진 몇 장 (인식 학습용)
  • 레일 속도와 그 자리 조명 상태, 라벨에 바코드 있는지
  • 카메라 달 레일 앞·뒤 공간 사진 (설치 위치 잡기용)

안전

  • 카메라 시스템은 지켜보기만 — 기존 생산 라인을 멈추거나 기계를 바꾸지 않습니다.
  • 코더 연동(2단계)은 사람이 손으로 하던 ‘메시지 고르기’와 같은 신호만 보냅니다 — 인쇄 품질·밀봉 기능은 건드리지 않습니다. 현장 실사·확인 후 진행합니다.

정확한 비용·일정은 코더 모델·포트 확인과 현장 실사 후 확정됩니다.
