카메라 2대는 기존 라인을 지켜보기만 합니다 — 라인을 멈추거나 기계를 건드리지 않습니다.

요청 3가지, 각각 되는지

1앞·뒤 카메라로 세서 대조 → 태블릿 표시 확실히 됨

  • 1~2초마다 두 카메라가 촬영 → 제품 종류와 개수를 자동 인식
  • 라벨 전(실물 수)과 라벨 후(라벨 수)를 대조, 안 맞으면 즉시 경보
  • 라벨의 글자·바코드까지 확인 → 엉뚱한 라벨(한우오색 자리에 단호박)도 잡아냄
  • 태블릿엔 품목별 실시간 집계 표 (실물 / 라벨 / 차이)
예: 실물 12개 · 라벨 14개 → “라벨 2개 초과” 빨간 경보로 바로 표시
팁 — 라벨에 바코드가 있으면 뒤 카메라를 바코드 리더로 두는 방법이 있습니다. 그러면 검수 정확도가 거의 100%, 비용도 더 쌉니다.

2라벨 바꿀 때를 스스로 감지 → 알림 됨

  • 레일 위 제품 종류를 계속 인식 → 한우오색이 끝나고 단호박이 시작되는 순간을 자동 감지
  • “이제 단호박으로 바꾸세요” 알림 (태블릿·소리)
  • 요청하신 대로 개수를 미리 입력하지 않습니다 — 그냥 보고 판단
  • 쟁반을 올리기 전 한 장 찍어두면 다음에 뭐가 올지 미리 알 수도 있음 (선택)

3제어 기능 없는 기계에 보조장치로 제어 추가 기계에 따라 됨

지금 바로 되는 것 — “바꿀 때”를 감지해 사람에게 알림. 기계 손 안 대고, 위험 0. 가치의 대부분이 여기서 나옵니다.
기계를 자동으로 바꾸는 것은 기계에 달렸습니다:
  • 랜·시리얼 포트가 있고 디지털로 라벨을 바꾸는 기계 → 명령을 보내 자동 전환 (가장 깔끔)
  • 버튼만 있는 기계 → 버튼 위에 누르는 장치(작은 액추에이터·릴레이)를 얹어 자동화
  • 라벨 롤을 손으로 갈아 끼우는 방식 → 자동화는 로봇팔급이라 배보다 배꼽 → 알림만 권장

→ 어느 쪽인지는 기계를 봐야 정해집니다. 그래서 아래 정보가 필요합니다.

다음 단계로 필요한 것 (기계 정보)

  • 라벨기 제조사·모델명 (기계 명판 사진 한 장)
  • 지금 라벨 바꾸는 장면 영상 — 손으로 무엇을 어떻게 하는지
  • 라벨을 기계가 인쇄하나, 인쇄된 라벨을 붙이나?
  • 기계에 포트(랜·USB·시리얼)가 있나?
  • 레일 속도·조명 상태, 라벨에 바코드 있는지
  • 제품 종류 목록 + 품목별 샘플 사진 (인식 학습용)

안전

  • 카메라 시스템은 지켜보기만 — 기존 생산 라인을 멈추거나 기계를 바꾸지 않습니다.
  • 기계 개조(2단계)는 현장 실사·안전 확인 후에만 진행합니다.

정확한 비용·일정은 기계 실사 후 확정됩니다.
